## 🧭 Overview

**gatherly** is a full-featured web application built with **Next.js**, **TailwindCSS**, and **React Query**, designed to simplify event planning and gift exchanges.

The project prioritizes maintainability, internationalization, and testing to deliver a strong developer experience.

### Core Features

- 🎁 **Gift Registry** – Create and view gifts (name, recipient, occasion, due date, budget, store link, image, privacy). Filter and sort the registry list; mark items as claimed, purchased, or sent. Available at `/gift-registry`.
- 🧪 **End-to-End Testing** – Integrated Cypress setup for reliable UI testing
- 📦 **Dependency Management** – Locked dependencies via `pnpm-lock.yaml`
- 🌐 **Internationalization** – Multilingual support with seamless language switching
- 🎨 **Styling & Build** – Custom TailwindCSS configuration and optimized builds
- 🔧 **Modular Architecture** – Clean separation of components, pages, and contexts
- 🛠️ **Quality Assurance** – Jest, React Testing Library, and custom matchers

## 🚀 Getting Started

### Prerequisites

This project requires:

- **Programming Language:** TypeScript
- **Package Manager:** pnpm

---

### Installation

Build **gatherly** from source and install dependencies:

1. **Clone the repository**

```
 git clone https://github.com/DihanVermeulen/gatherly
```

2. Navigate to the project directory

```
    cd gatherly
```

3. Install dependencies

```
    pnpm install
```

## Usage

Run the development server:

```
    pnpm dev
```

Test:

```
  pnpm test
```
