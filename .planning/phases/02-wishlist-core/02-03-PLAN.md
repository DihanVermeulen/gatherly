Create a bottom drawer form component for creating and editing wishlist items.

**Component API:**
```typescript
type WishlistFormProps = {
  isOpen: boolean;
  onClose: () => void;
  onSave: (data: WishlistFormData) => void;
  editItem?: WishlistItem | null;  // null/undefined = create mode, populated = edit mode
  isSaving?: boolean;
};

type WishlistFormData = {
  itemName: string;
  description: string;
  productUrl: string;
  priority: 'low' | 'medium' | 'high';
  imageUrl: string | null;
};
```

**Visual design (from CONTEXT.md decisions):**
- Bottom drawer slides up when opened (CSS transform translateY transition)
- Semi-transparent backdrop overlay that closes drawer on tap
- Drawer has rounded top corners (rounded-t-2xl), white/dark bg
- Handle bar at top (small centered gray bar, visual affordance)
- Field order: Image upload → Name → Description → URL → Priority
- Save button at bottom: primary green, full width

**Image upload section:**
- Three upload methods accessible via file input:
  1. Camera capture: `<input type="file" accept="image/*" capture="environment">` (separate button)
  2. Gallery picker: `<input type="file" accept="image/*">` (separate button)
  3. Paste URL: text input field that appears when "Paste URL" tab is tapped
- Image preview: Show selected image in a square container, remove button overlay
- No-image state: Gift box icon from lucide-react (Gift or Package icon)
- Use `compressImage()` from imageCompression.ts when file selected
- Use `compressImageFromUrl()` when URL pasted
- Show uploading spinner during compression
- If wasLargeImage from compression result, show small warning text: "Large image compressed for storage"

**Form fields:**
- Name: text input, required, placeholder "e.g., Blue Headphones", max 120 chars
- Description: textarea, optional, placeholder "Details about the item...", max 500 chars
- Product URL: url input, optional, placeholder "https://...", max 500 chars
- Priority: select/segmented control with Low/Medium/High options, default Medium
- Validate on blur using validateWishlistForm from wishlistValidation.ts
- Show inline error messages below fields in red text

**State management:**
- useState for formData object (itemName, description, productUrl, priority, imageUrl)
- useState for errors (WishlistFormErrors from validation)
- useState for uploading (boolean, during image compression)
- When editItem changes and isOpen becomes true, populate form with editItem data
- When isOpen becomes false, reset form to defaults
- On save: validate, if valid call onSave(formData), parent handles API call and closing

**Styling (Tailwind classes matching gift-registry.html design):**
- Backdrop: `fixed inset-0 z-40 bg-black/50`
- Drawer: `fixed bottom-0 left-0 right-0 z-50 bg-white dark:bg-[#1a2e20] rounded-t-2xl max-h-[90vh] overflow-y-auto`
- Transition: `transition-transform duration-300 ease-out` with translateY(100%) when closed, translateY(0) when open
- Form padding: `p-6`
- Input fields: standard Tailwind form styling (bg-gray-50 dark:bg-gray-800 rounded-lg p-3 border)
- Save button: `w-full h-12 rounded-xl bg-primary text-[#0d1b12] font-bold`
