Create `apps/api/src/routes/wishlists.ts` following the exact pattern from `apps/api/src/routes/gifts.ts`:

**Endpoints to create:**

1. **GET `/:eventId/wishlists`** — List all wishlist items for an event
   - JOIN wishlists with participants (for participant_name) and LEFT JOIN wishlist_claims (for claimed_by)
   - Map snake_case DB columns to camelCase response: `{ id, eventId, participantId, participantName, itemName, description, imageUrl, productUrl, priority, claimedBy, claimedByName, createdAt, updatedAt }`
   - To get claimedByName: LEFT JOIN wishlist_claims wc ON w.id = wc.wishlist_id, then LEFT JOIN participants cp ON wc.claimed_by = cp.id
   - ORDER BY w.created_at DESC

2. **POST `/:eventId/wishlists`** — Create wishlist item
   - Required body fields: `participantId`, `itemName`
   - Optional body fields: `description`, `imageUrl`, `productUrl`, `priority` (default 'medium')
   - Validate: itemName must be non-empty after trim
   - Validate: participantId must be provided
   - INSERT INTO wishlists, RETURNING *
   - Return 201 with camelCase mapped item

3. **PUT `/:eventId/wishlists/:id`** — Update wishlist item (owner only)
   - Body includes `participantId` for authorization check
   - First query: SELECT participant_id FROM wishlists WHERE id = $1 AND event_id = $2
   - If not found: 404
   - If participant_id !== parseInt(participantId): 403 "Unauthorized - can only edit your own items"
   - UPDATE wishlists SET item_name, description, image_url, product_url, priority WHERE id AND event_id
   - RETURNING * and map to camelCase

4. **DELETE `/:eventId/wishlists/:id`** — Delete wishlist item (owner only)
   - Body includes `participantId` for authorization
   - Same ownership check pattern as PUT
   - DELETE FROM wishlists WHERE id = $1 AND event_id = $2
   - Return { success: true }

**Important implementation details:**
- Import `{ Router, Request, Response }` from "express" and `{ query }` from "../db/connection"
- Use parameterized queries ($1, $2, etc.) for SQL injection prevention
- parseInt() on participantId from body when comparing with DB integer values
- Export default router

Create `apps/gatherly/src/api/wishlists.ts` following the pattern from `apps/gatherly/src/api/gifts.ts`:

```typescript
import apiClient from "./client";
import { WishlistItem } from "./events"; // Type already exists from Phase 1

export const wishlistsApi = {
  // Get all wishlist items for an event
  getAll: async (eventId: string): Promise<WishlistItem[]> => {
    const response = await apiClient.get(`/api/events/${eventId}/wishlists`);
    return response.data;
  },

  // Create wishlist item
  create: async (
    eventId: string,
    item: {
      participantId: number;
      itemName: string;
      description?: string;
      imageUrl?: string;
      productUrl?: string;
      priority?: 'low' | 'medium' | 'high';
    }
  ): Promise<WishlistItem> => {
    const response = await apiClient.post(`/api/events/${eventId}/wishlists`, item);
    return response.data;
  },

  // Update wishlist item
  update: async (
    eventId: string,
    itemId: number,
    item: {
      participantId: number;
      itemName: string;
      description?: string;
      imageUrl?: string;
      productUrl?: string;
      priority?: 'low' | 'medium' | 'high';
    }
  ): Promise<WishlistItem> => {
    const response = await apiClient.put(`/api/events/${eventId}/wishlists/${itemId}`, item);
    return response.data;
  },

  // Delete wishlist item
  delete: async (eventId: string, itemId: number, participantId: number): Promise<void> => {
    await apiClient.delete(`/api/events/${eventId}/wishlists/${itemId}`, {
      data: { participantId }
    });
  },
};

export default wishlistsApi;
```

Note: The delete method uses `{ data: { participantId } }` because axios requires body data for DELETE requests to be in the `data` config property.
