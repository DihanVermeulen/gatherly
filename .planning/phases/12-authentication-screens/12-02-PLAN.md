**Step 1: Update backend /refresh endpoint to accept body fallback**

In `apps/api/src/routes/auth.ts`, line ~166, change:
```typescript
const refreshToken = req.cookies.refreshToken;
```
to:
```typescript
const refreshToken = req.cookies.refreshToken || req.body?.refreshToken;
```

This is a one-line change. The rest of the refresh logic remains unchanged. This allows the mobile app to send a stored refreshToken in the request body when cookies don't persist across app restarts.
