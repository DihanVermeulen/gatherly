```typescript
let _pendingMagicToken: string | null = null;

export function setPendingMagicToken(token: string): void {
  _pendingMagicToken = token;
}

export function consumePendingMagicToken(): string | null {
  const token = _pendingMagicToken;
  _pendingMagicToken = null;
  return token;
}
```

Keep the existing `_pendingInviteCode`, `setPendingInviteCode`, and `consumePendingInviteCode` functions unchanged.

The updated useEffect should look like:

useEffect(() => {
  if (session && !isLoading) {
    const magicToken = consumePendingMagicToken();
    if (magicToken) {

      const timer = setTimeout(() => {
        router.replace(`/join?token=${pendingCode}`);
      }, 100);
      return () => clearTimeout(timer);
    }
  }

Rewrite `apps/gatherly-mobile/app/magic-link/[token].tsx` with the following state machine and UI:

**State machine:**
```typescript
type MagicLinkState =
  | "loading"        // calling /lookup
  | "preview"        // show event info + choice (or auto-show Join if logged in)
  | "name-prompt"    // without-account path: full-screen name input
  | "joining"        // calling /redeem
  | "success"        // auto-dismiss 1.5s then event-details
  | "already-joined" // user already a participant
  | "invalid"        // token expired/not-found
  | "error";         // network or unexpected error
```

**State variables:**
- `state: MagicLinkState` — starts at "loading"
- `eventId: number | null`
- `eventName: string | null`
- `organizerName: string | null`
- `participantCount: number`
- `eventDate: string | null`
- `participantName: string` — for name prompt input
- `isSubmittingName: boolean`

**On mount (useEffect):**
1. If no token param, set state to "invalid"
2. Call `authApi.lookupMagicLink(token)` (from Plan 01)
3. On success: store event preview data (eventId, eventName, organizerName, participantCount, eventDate)
4. Check already-joined: if user is logged in (`session` exists), check if `events` array contains an event with matching eventId AND the user's name is in `people`. If so → "already-joined"
5. Otherwise → "preview"
6. On 401 error → "invalid"
7. On other error → "error"

**Preview state — logged-in user (`session` is truthy):**
- Show hero block with event name (colored rectangle, same HERO_COLORS array as join.tsx)
- Below hero: event name heading, "Hosted by {organizerName}" (if available), "{participantCount} participants" (if > 0), event date (if available)
- Single "Join Event" button
- On press: call `handleJoin()`

**Preview state — logged-out user (`session` is falsy):**
- Same hero block and event details as above
- TWO buttons stacked vertically:
  - "Join with account" (primary solid button) — calls `handleJoinWithAccount()`
  - "Continue without account" (outline button) — sets state to "name-prompt"

**handleJoin() (for logged-in users):**
1. Guard: if state === "joining", return
2. Set state to "joining"
3. Call `authApi.redeemMagicLink(token, user?.email)` — this creates participant + returns JWT
4. Detect response shape (user-scoped vs participant-scoped, same logic as current code)
5. Call `signIn(response.accessToken, response.user)`
6. Store eventId from response
7. Set state to "success"
8. On error: if 401/400 → "invalid"; else → "error"

**handleJoinWithAccount():**
1. Call `setPendingMagicToken(token)` — stores the magic token for the auth round-trip
2. Call `router.push("/sign-in" as never)`
3. After auth completes, `_layout.tsx` useEffect fires, calls `consumePendingMagicToken()`, redirects back to `/magic-link/{token}` where the flow restarts from the /lookup step. This time the user IS logged in, so they see the "Join Event" button.

**Name-prompt state:**
- Full-screen centered layout
- Heading: "What's your name?"
- Subtext: "You're joining {eventName}. How should we introduce you?" (or generic if no eventName)
- Text input (autoFocus, returnKeyType "done", onSubmitEditing triggers submit)
- "Join Event" button (disabled while name is empty or submitting; shows spinner while submitting)
- On submit: call `handleNameSubmit()`

**handleNameSubmit():**
1. Validate name is non-empty
2. Set isSubmittingName to true
3. Call `authApi.redeemMagicLink(token, undefined, participantName.trim())` — creates participant with name + returns participant-scoped JWT
4. Call `signIn(response.accessToken, response.user)`
5. Store eventId from response
6. Set state to "success"
7. On error: set state to "error", isSubmittingName to false

**Success state:**
- Centered layout with green CheckCircle icon (64px, #10b981)
- Heading: "Welcome!"
- Subtext: "Taking you to {eventName}..."
- useEffect: after 1.5 seconds, call `router.push(\`/event-details?id=${eventId}\` as never)` — uses router.push for back navigation

**Already-joined state:**
- Hero block + "You're already a member" heading + "You've already joined {eventName}" text
- "View Event" button → `router.push(\`/event-details?id=${eventId}\` as never)`

**Invalid state:**

- "This link is no longer valid" heading

**Error state:**

- "Something went wrong" heading

- "Try Again" button → reset state to "loading" and re-run lookup
