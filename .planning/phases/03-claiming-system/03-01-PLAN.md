Add two new routes to the wishlists router:

**POST /:eventId/wishlists/:id/claim**
1. Guard: if `!req.user?.participantId` return 403 `{ error: "Participants only" }` — organizer sessions have no participantId.
2. Self-claim guard: Query `SELECT participant_id FROM wishlists WHERE id = $1 AND event_id = $2`. If `participant_id === req.user.participantId`, return 403 `{ error: "Cannot claim your own item" }`.
3. If wishlist item not found (rowCount === 0), return 404.
4. Atomic insert: `INSERT INTO wishlist_claims (wishlist_id, claimed_by) VALUES ($1, $2) ON CONFLICT (wishlist_id) DO NOTHING RETURNING id`. Use `req.user.participantId` as `claimed_by`.
5. If `result.rowCount === 0`, return 409 `{ error: "Item already claimed" }`.
6. Return 201 `{ success: true }`.

**DELETE /:eventId/wishlists/:id/claim**
1. Guard: if `!req.user?.participantId` return 403 `{ error: "Participants only" }`.
2. Delete only own claim: `DELETE FROM wishlist_claims WHERE wishlist_id = $1 AND claimed_by = $2` using `req.user.participantId`.
3. If `result.rowCount === 0`, return 404 `{ error: "No claim found" }`.
4. Return 200 `{ success: true }`.
