  <action>
    **Create `apps/gatherly-mobile/app/view-wishlists.tsx`** — the Event Wishlists browse + claim screen.

    Match the screen template at `screen-templates/Wishlists.png`. Use the same screen structure as `my-wishlist.tsx` as a pattern reference.

    **Screen structure:**
    - Header: "Wishlists" title, event name as subtitle (same header pattern as my-wishlist.tsx)
    - Back button in header (router.back())
    - SectionList (NOT FlatList) for grouped participant sections
    - Loading state: ActivityIndicator while fetching
    - Empty state: centered icon + "No wishlist items yet" message

    **Data fetching (on mount, parallel):**
    - `eventsApi.getById(id)` for participantDetails (to derive myParticipantId)
    - `wishlistsApi.getAll(id)` for all wishlist items with isClaimed/claimedByMe
    - Dispatch `SET_WISHLISTS` with fetched items
    - Derive `myParticipantId` from participantDetails: `participantDetails.find(p => p.name === user?.name)?.id`
    - Use `useSession()` to get `user` for name matching

    **SectionList sections (useMemo):**
    - Group items by `participantId` using a Map
    - "My Wishlist" section first (if user has items), with `isOwn: true`
    - Other sections alphabetically by participant name, with `isOwn: false`
    - Hide sections with zero items (only show participants who have wishlist items)
    - Section type: `{ participantId: number; title: string; isOwn: boolean; data: TWishlistItem[] }`

    **Card rendering (renderItem):**
    - Show: item name, image thumbnail (if exists), priority badge (Low=gray, Medium=amber, High=red)
    - **Own unclaimed items:** Full opacity, no claim indicators
    - **Own claimed items:** Full opacity, subtle CheckCircle icon (teal) in corner — NOT grayed out
    - **Others' unclaimed items:** Full opacity, normal appearance
    - **Others' claimed items:** `opacity-50`, "Claimed" label badge — grayed out
    - All items wrapped in Pressable with `onLongPress`

    **Long-press ActionSheet (3 modes):**
    - State: `{ item: TWishlistItem; mode: 'edit' | 'claim' | 'unclaim' } | null`
    - **Own items** (`isOwn: true`): mode = 'edit' -> show Edit / Delete / Cancel
      - Edit: `router.push('/edit-wishlist-item?id=${item.id}&eventId=${id}')`
      - Delete: show AlertDialog confirmation, then optimistic delete (same as my-wishlist.tsx pattern: dispatch DELETE_WISHLIST_ITEM, call wishlistsApi.delete, revert with SET_WISHLISTS on failure)
    - **Others' unclaimed** (`!isOwn && !item.isClaimed`): mode = 'claim' -> show Claim / Cancel
    - **Others' claimed by me** (`!isOwn && item.claimedByMe`): mode = 'unclaim' -> show Unclaim / Cancel
    - **Others' claimed by someone else** (`!isOwn && item.isClaimed && !item.claimedByMe`): do nothing (no ActionSheet)

    **Claim handler (optimistic):**
    1. Close ActionSheet (`setActionsheetItem(null)`)
    2. Dispatch `CLAIM_WISHLIST_ITEM` with `{ eventId: id, itemId: item.id }` (optimistic)
    3. Show success toast: "Claimed!" (action="success", placement="top", duration=2000)
    4. Call `wishlistsApi.claim(id, item.id)` in background
    5. On failure: dispatch `UNCLAIM_WISHLIST_ITEM` to revert, show error toast
    6. On 409 conflict: revert + refresh wishlists via `wishlistsApi.getAll(id)` + `SET_WISHLISTS` dispatch + show "Already claimed by someone else" toast

    **Unclaim handler (optimistic):**
    1. Close ActionSheet
    2. Dispatch `UNCLAIM_WISHLIST_ITEM` with `{ eventId: id, itemId: item.id }` (optimistic)
    3. Show toast: "Unclaimed" (action="muted", placement="top", duration=2000)
    4. Call `wishlistsApi.unclaim(id, item.id)` in background
    5. On failure: dispatch `CLAIM_WISHLIST_ITEM` to revert, show error toast

    **Toast usage:**
    ```typescript
    import { useToast, Toast, ToastTitle } from "@/components/ui/toast";
    ```

    **ActionSheet imports:** Same as my-wishlist.tsx — Actionsheet, ActionsheetBackdrop, ActionsheetContent, ActionsheetDragIndicatorWrapper, ActionsheetDragIndicator, ActionsheetItem, ActionsheetItemText from `@/components/ui/actionsheet`.

    **AlertDialog for delete:** Same as my-wishlist.tsx pattern — AlertDialog with "Are you sure?" confirmation.

    **Section header rendering:**
    - "My Wishlist" section: distinct visual treatment (e.g., different background tint or border-left accent)
    - Other sections: participant name as header text
    - Use `renderSectionHeader` prop on SectionList

    **SectionList props:**
    - `stickySectionHeadersEnabled={false}`
    - `contentContainerStyle={{ paddingHorizontal: 16, paddingBottom: 120, paddingTop: 8 }}`
    - `keyExtractor={(item) => String(item.id)}`

    **Route params:** Use `useLocalSearchParams` from expo-router to get `id` (event ID) from query string: `const { id } = useLocalSearchParams<{ id: string }>();`

    **Register route** in `apps/gatherly-mobile/app/_layout.tsx`:
    Add inside `Stack.Protected guard={!!session}`, after the `edit-wishlist-item` Screen:
    ```tsx
    <Stack.Screen name="view-wishlists" options={{ headerShown: false }} />
    ```

    **Wire Event Details button** in `apps/gatherly-mobile/app/event-details.tsx`:
    Find the "View All Gifts" button stub (the one with `console.log("View All Gifts — coming soon")`).
    - Change button label from "View All Gifts" to "View Wishlists"
    - Change onPress to: `router.push('/view-wishlists?id=' + id)`
    - Keep the Gift icon (or change to ListChecks icon from lucide-react-native if it looks better)
