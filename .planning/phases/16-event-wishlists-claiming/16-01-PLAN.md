  <action>
    **1. Extend TWishlistItem type** in `apps/gatherly-mobile/app/api/events.ts`:
    Add two new fields to the existing TWishlistItem type:
    ```
    isClaimed: boolean;
    claimedByMe: boolean;
    ```
    Place them after the `priority` field, before the legacy `claimedBy` field. Keep legacy fields (`claimedBy`, `claimedByName`) for backward compatibility.

    **2. Add claim/unclaim methods** to `apps/gatherly-mobile/app/api/wishlists.ts`:
    Add two new methods to the existing `wishlistsApi` object:
    ```typescript
    // Claim a wishlist item (POST, no body needed — backend uses JWT participantId)
    claim: async (eventId: string, itemId: number): Promise<void> => {
      await apiClient.post(`/api/events/${eventId}/wishlists/${itemId}/claim`);
    },

    // Unclaim a wishlist item (DELETE, no body needed)
    unclaim: async (eventId: string, itemId: number): Promise<void> => {
      await apiClient.delete(`/api/events/${eventId}/wishlists/${itemId}/claim`);
    },
    ```
    Add these after the existing `delete` method, before the closing `};`.

    **3. Add CLAIM/UNCLAIM reducer actions** to `apps/gatherly-mobile/app/contexts/EventsContext.tsx`:

    Add two new action types to the `EventsAction` union:
    ```typescript
    | { type: "CLAIM_WISHLIST_ITEM"; payload: { eventId: string; itemId: number } }
    | { type: "UNCLAIM_WISHLIST_ITEM"; payload: { eventId: string; itemId: number } }
    ```

    Add two new reducer cases before the `default` case:
    ```typescript
    case "CLAIM_WISHLIST_ITEM":
      return {
        ...state,
        events: state.events.map((event) =>
          event.id === action.payload.eventId
            ? {
                ...event,
                wishlists: (event.wishlists || []).map((item) =>
                  item.id === action.payload.itemId
                    ? { ...item, isClaimed: true, claimedByMe: true }
                    : item
                ),
              }
            : event
        ),
      };
    case "UNCLAIM_WISHLIST_ITEM":
      return {
        ...state,
        events: state.events.map((event) =>
          event.id === action.payload.eventId
            ? {
                ...event,
                wishlists: (event.wishlists || []).map((item) =>
                  item.id === action.payload.itemId
                    ? { ...item, isClaimed: false, claimedByMe: false }
                    : item
                ),
              }
            : event
        ),
      };
    ```

    **Important:** The eventId is a `string` (not number) — consistent with existing reducer actions like SET_WISHLISTS, DELETE_WISHLIST_ITEM.
