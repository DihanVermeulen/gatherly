  <action>
1. Install expo-sqlite:
   ```
   cd apps/gatherly-mobile && npx expo install expo-sqlite
   ```
   expo-sqlite is part of Expo SDK 54, so `npx expo install` ensures the correct version.

2. Create `apps/gatherly-mobile/lib/database.ts`:
   - Export an `initDatabase()` async function that:
     - Opens database named `gatherly.db` using `SQLite.openDatabaseAsync('gatherly.db')`
     - Runs `PRAGMA journal_mode = WAL;` for crash resilience
     - Creates tables with `CREATE TABLE IF NOT EXISTS`:
       - `events` (id TEXT PRIMARY KEY, name TEXT NOT NULL, date TEXT, participant_count INTEGER DEFAULT 0, gift_count INTEGER DEFAULT 0, data TEXT NOT NULL, cached_at INTEGER NOT NULL)
       - `cache_meta` (key TEXT PRIMARY KEY, value TEXT, updated_at INTEGER NOT NULL)
     - NOTE: There is NO wishlist_items table. Wishlists are embedded in the event JSON blob (event.wishlists array) and cached as part of the event data column.
   - Use a module-level singleton pattern: `let db: SQLiteDatabase | null = null;` so repeated calls return same instance
   - Export the `SQLiteDatabase` type from expo-sqlite for consumers

3. Create `apps/gatherly-mobile/lib/cache.ts`:
   - Import `SQLiteDatabase` from expo-sqlite
   - Export `cacheEvents(db, events: TEvent[])`: wraps in `db.withTransactionAsync`, does INSERT OR REPLACE for each event (id, name, date, participant_count from participants.length, gift_count from giftCount, JSON.stringify(event) as data, Date.now() as cached_at). Also delete events from cache that are no longer in the array (DELETE WHERE id NOT IN (...)).
   - Export `loadCachedEvents(db)`: SELECT data FROM events ORDER BY cached_at DESC, parse JSON, return TEvent[].
   - Export `clearCache(db)`: DELETE FROM events; DELETE FROM cache_meta; (used on logout)
   - NOTE: Do NOT create cacheWishlistItems or loadCachedWishlistItems. Wishlists are embedded in event.wishlists and cached implicitly via cacheEvents.
   - Use the TEvent type from `@/app/api/events` (aliased as Event in that file, but import the type alias)
  </action>

    - `cd apps/gatherly-mobile && npx tsc --noEmit --pretty 2>&1 | head -30` (no errors in new files)
    - Confirm database.ts exists and exports initDatabase
    - Confirm cache.ts exists and exports cacheEvents, loadCachedEvents, clearCache (and NOT cacheWishlistItems)

   - Create a React context holding `SQLiteDatabase | null`
   - `DatabaseProvider` component:
     - Uses useState for db instance
     - Uses useEffect to call `initDatabase()` from `@/lib/database` on mount, sets db when ready
     - While db is null, render a minimal loading view (just a View with ActivityIndicator — import from react-native). Do NOT render children until db is ready, so downstream consumers can safely use useDatabase().

   - `useDatabase()` hook:
     - Gets db from context
     - Throws if null (should never happen since Provider blocks rendering until ready)
     - Returns typed `SQLiteDatabase`
