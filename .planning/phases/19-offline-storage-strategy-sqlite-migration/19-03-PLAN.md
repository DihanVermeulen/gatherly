2. Create `apps/gatherly-mobile/hooks/useNetworkStatus.ts`:
   ```typescript
   import { useState, useEffect } from "react";
   import NetInfo from "@react-native-community/netinfo";

   /**
    * Hook for monitoring network connectivity using NetInfo.
    * Returns `true` when connected, `false` when offline, `null` while initializing.
    */
   export function useNetworkStatus(): boolean | null {
     const [isConnected, setIsConnected] = useState<boolean | null>(null);

     useEffect(() => {
       const unsubscribe = NetInfo.addEventListener((state) => {
         setIsConnected(state.isConnected);
       });
       return unsubscribe;
     }, []);

     return isConnected;
   }
   ```
   This is a clean, focused hook. Keep it simple — just connectivity state, nothing else.

  <action>
Enforce the phase requirement "read-only offline: no mutations without API connection" by adding `networkMode: 'online'` to every `useMutation` call. This tells React Query to pause mutations when offline instead of firing them and failing.

There is NO central QueryClient config in the codebase (no `new QueryClient()` found — React Query is likely provided by a parent context or will be added in Plan 01). Therefore, add `networkMode: 'online'` to each individual `useMutation` options object.

1. Update `apps/gatherly-mobile/hooks/useEventMutations.ts`:
   Add `networkMode: 'online'` to each of the three `useMutation` calls:
   - `useCreateEvent`: Add `networkMode: 'online',` after `mutationKey: ["event", "create"],`
   - `useUpdateEvent`: Add `networkMode: 'online',` after `mutationKey: ["event", "update"],`
   - `useDeleteEvent`: Add `networkMode: 'online',` after `mutationKey: ["event", "delete"],`

2. Update `apps/gatherly-mobile/hooks/useWishlistMutations.ts`:
   Add `networkMode: 'online'` to each of the three `useMutation` calls:
   - `useClaimWishlistItem`: Add `networkMode: 'online',` after `mutationKey: ["wishlist", "claim"],`
   - `useUnclaimWishlistItem`: Add `networkMode: 'online',` after `mutationKey: ["wishlist", "unclaim"],`
   - `useReorderWishlistItems`: Add `networkMode: 'online',` after `mutationKey: ["wishlist", "reorder"],`

When `networkMode: 'online'` is set, React Query will:
- NOT fire the mutationFn when offline
- Keep the mutation in a "paused" state
- Automatically resume when connectivity is restored
- The optimistic updates in onMutate will NOT run while paused

This prevents the app from attempting API calls that will fail offline, enforcing the read-only cache strategy.
