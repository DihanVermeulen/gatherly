<task type="auto">
  <name>Task 1: Create auth routes (register, login, refresh, logout)</name>
  <files>apps/api/src/routes/auth.ts</files>
  <action>
    Create `apps/api/src/routes/auth.ts` with Express Router exporting four endpoints:

    **POST /register**:
    - Accept { email, password, name } in request body
    - Validate: all three fields required, email format basic check, password min 8 chars
    - Check if user with email already exists in users table -> 409 { error: 'User already exists' }
    - Hash password with bcrypt (saltRounds = 12)
    - INSERT into users (email, name, password_hash, role) VALUES ($1, $2, $3, 'participant') RETURNING id, email, name, role
    - Call generateTokens({ userId: user.id, email: user.email, role: user.role })
    - Set refreshToken in HttpOnly cookie: res.cookie('refreshToken', tokens.refreshToken, { httpOnly: true, secure: process.env.NODE_ENV === 'production', sameSite: 'strict', maxAge: 7 * 24 * 60 * 60 * 1000, path: '/api/auth' })
    - Return 201 { accessToken, user: { id, email, name, role } }

    **POST /login**:
    - Accept { email, password } in request body
    - Validate: both required
    - Query users table by email. If not found -> 401 { error: 'Invalid credentials' }
    - bcrypt.compare(password, user.password_hash). If false -> 401 { error: 'Invalid credentials' }
    - Use same generic error message for both "user not found" and "wrong password" to prevent user enumeration
    - Call generateTokens, set refresh cookie (same pattern as register), return 200 { accessToken, user }

    **POST /refresh**:
    - Read refreshToken from req.cookies.refreshToken
    - If missing -> 401 { error: 'No refresh token' }
    - Call verifyRefreshToken(refreshToken) - this checks signature AND database
    - If invalid or not in DB -> 401 { error: 'Invalid refresh token' }
    - Revoke old refresh token: revokeRefreshToken(hash of old token)
    - Call cleanExpiredTokens() to clean up (opportunistic cleanup)
    - Generate new token pair with generateTokens
    - Set new refresh cookie, return 200 { accessToken, user: { id, email, name, role } }
    - Query user from DB to get current name/role (not from old token, in case they changed)

    **POST /logout**:
    - Read refreshToken from req.cookies.refreshToken
    - If present, revoke it from DB: revokeRefreshToken(hash)
    - Clear the cookie: res.clearCookie('refreshToken', { httpOnly: true, secure: process.env.NODE_ENV === 'production', sameSite: 'strict', path: '/api/auth' })
    - Return 200 { message: 'Logged out' }
    - Logout should always succeed (even if no token present)

    Import bcrypt, query from db/connection, and token service functions.
    Use try/catch for all routes with console.error logging and 500 response on unexpected errors.
