<objective>
Configure `apps/gatherly-mobile/app.json` with iOS Universal Links (`associatedDomains`) and Android App Links (`intentFilters`) so the Expo app is registered as the handler for `https://YOUR_DOMAIN/magic-link/*` URLs.

Purpose: Universal Links and App Links require the native app to declare which HTTPS domains and paths it handles. Without this config, the OS cannot intercept the link and open the app — it always falls back to the browser. This config, combined with the AASA/assetlinks.json files from Plan 01, completes the two-sided handshake.

Output: Updated `app.json` ready for an EAS Build that will register the Associated Domains entitlement with Apple and configure Android intent filters.
</objective>
