  <action>
    Create a full-screen edit screen following the same layout pattern as `edit-event.tsx`.

    Route params: `useLocalSearchParams<{ id: string; eventId: string }>()` where `id` is the wishlist item ID and `eventId` is the event ID.

    On mount:
    1. Get event from EventsContext: `events.find(e => e.id === eventId)`
    2. Find the wishlist item: `event.wishlists?.find(w => w.id === Number(id))`
    3. If item not found, show "Item not found" with back button (same pattern as event-details 404)
    4. Need participantId for the update call — get it from the item itself: `item.participantId`

    Pre-fill local state from item:
    - `itemName` (string) = item.itemName
    - `description` (string) = item.description || ""
    - `imageUrl` (string | null) = item.imageUrl || null
    - `priority` ("low" | "medium" | "high") = item.priority

    Header: Back arrow (ArrowLeft) + title "Edit Item" + Save button (text or Pressable, teal-500 color). Same header pattern as edit-event.tsx.

    Form (ScrollView with KeyboardAvoidingView):
    - Item Name: TextInput with label, required. Style: rounded-xl border border-outline-200 px-4 py-3
    - Description: TextInput multiline (4 lines), optional. Same styling.
    - Image: If imageUrl exists, show Image preview (rounded-xl, h-48, full width) with an "x" overlay button to remove. Below: "Change Image" / "Add Image" Pressable. Uses same expo-image-picker pattern as AddWishlistItem from Plan 01: `launchImageLibraryAsync` with `base64: true, quality: 0.5, allowsEditing: true, aspect: [4, 3]`. Call `requestMediaLibraryPermissionsAsync()` before opening.
    - Priority: Segmented control — 3 adjacent Pressable buttons (Low / Medium / High). Active button: teal-500 bg + white text. Inactive: background-100 + typography-600. Same exact component pattern as AddWishlistItem.

    Save button behavior:
    1. Validate itemName is non-empty (show error text if empty)
    2. Show ActivityIndicator while saving
    3. Call `wishlistsApi.update(eventId, Number(id), { participantId: item.participantId, itemName: itemName.trim(), description: description || undefined, imageUrl: imageUrl || undefined, priority })`
    4. Dispatch `UPDATE_WISHLIST_ITEM` with `{ eventId, item: updatedItem }`
    5. Call `router.back()`
    6. On error: show error text below save button, do NOT navigate away

    CRITICAL: The `participantId` for the update API call comes from the item object (`item.participantId`), NOT from user.id or a separate lookup.
  </action>
