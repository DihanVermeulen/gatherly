    **AddWishlistItem.tsx** — Bottom sheet form component for adding a wishlist item.

    Props: `{ eventId: string; participantId: number; onItemAdded: (item: TWishlistItem) => void; onClose: () => void }`.

    Form fields:
    - Item name (TextInput, required)
    - Description (TextInput, multiline, optional)
    - Image (Pressable thumbnail area — taps to open expo-image-picker via `launchImageLibraryAsync` with `base64: true, quality: 0.5, allowsEditing: true, aspect: [4, 3]`). Before launching picker, call `requestMediaLibraryPermissionsAsync()`. Store result as `data:image/jpeg;base64,${asset.base64}`.
    - Priority (segmented control — 3 adjacent Pressable buttons for Low / Medium / High, default Low). Active button gets teal-500 bg + white text, inactive gets background-100 + typography-600.

    Save button: calls `wishlistsApi.create(eventId, { participantId, itemName, description, imageUrl, priority })`, then calls `onItemAdded(createdItem)` and `onClose()`. Show ActivityIndicator while saving.

    Wrap form content in `BottomSheetScrollView` (from @gorhom/bottom-sheet) for keyboard awareness. Match the exact bottom sheet pattern from `(tabs)/index.tsx` (BottomSheet with enablePanDownToClose, BottomSheetBackdrop).

    **my-wishlist.tsx** — Main wishlist list screen.

    Route params: `useLocalSearchParams<{ id: string }>()` where `id` is eventId.

    On mount:
    1. Get event from EventsContext: `events.find(e => e.id === id)`
    2. Call `eventsApi.getById(id)` to get `participantDetails` (not included in getAll). Store in local state.
    3. Derive `myParticipantId = participantDetails.find(p => p.name === user?.name)?.id`
    4. Call `wishlistsApi.getAll(id)` and dispatch `SET_WISHLISTS` to populate `event.wishlists`
    5. Filter items: `myItems = (event.wishlists || []).filter(item => item.participantId === myParticipantId)`

    Header: Back arrow (ArrowLeft) + title "My Wishlist" — same pattern as event-details.tsx header.

    List: FlatList rendering WishlistCard items. Each card:
    - Rounded corners (rounded-2xl), slightly elevated (shadow-sm via style), white bg
    - If imageUrl exists: full-width Image at top of card with rounded top corners, height ~160
    - Card body (p-4): item name (font-bold, text-base) + priority text label (text-sm, text-typography-500, e.g. "Low", "Medium", "High")
    - `onLongPress` opens GlueStack Actionsheet with Edit / Delete / Cancel options
    - Store `selectedItem` in state to track which card was long-pressed

    ActionSheet (GlueStack): Three ActionsheetItems — Edit, Delete, Cancel.
    - Edit: `router.push(\`/edit-wishlist-item?id=${selectedItem.id}&eventId=${id}\`)` then close sheet
    - Delete: close ActionSheet, show GlueStack AlertDialog confirmation
    - Cancel: close ActionSheet

    Delete confirmation (GlueStack AlertDialog):
    - Title: "Delete Item"
    - Body: "Are you sure you want to delete {itemName}?"
    - Actions: Cancel + Delete (destructive red)
    - On confirm: dispatch `DELETE_WISHLIST_ITEM` immediately (optimistic), then call `wishlistsApi.delete(id, itemId, myParticipantId)`. On failure: call `wishlistsApi.getAll(id)` and dispatch `SET_WISHLISTS` to revert.

    FAB: Positioned absolute bottom-right (bottom-24 right-4), rounded-full, teal-500 bg, Plus icon (lucide). onPress expands the gorhom bottom sheet containing AddWishlistItem.

    When `onItemAdded` fires from AddWishlistItem: dispatch `ADD_WISHLIST_ITEM` with the created item.

    Empty state (when myItems.length === 0): Centered Gift icon (lucide, size 48, color #cbd5e1) + "No wishlist items yet" text + "Add your first item" Pressable that opens the bottom sheet.

    Loading state: ActivityIndicator while participantDetails or wishlists are loading.

    CRITICAL PITFALLS:
    - participantId for API calls comes from `participantDetails` (via eventsApi.getById), NOT from `user.id` — different tables
    - `event.wishlists` may be undefined on initial load — always use `|| []`
    - Use `BottomSheetScrollView` inside the bottom sheet for keyboard handling
