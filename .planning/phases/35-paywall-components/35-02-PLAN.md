    Create `app/pricing.tsx` as a default-exported screen component.

    **Route params:**
    - `const { eventId = '' } = useLocalSearchParams<{ eventId: string }>()`
    - eventId is passed by screens that route here; used for context but NOT for any API call in this screen

    **Screen structure:**
    ```
    SafeAreaView (flex: 1, backgroundColor: #ffffff, edges: ["bottom"])
    ├── AppHeader (title: "Plans", onBack: router.back())
    └── ScrollView (contentContainerStyle: padding 16, paddingBottom 40)
        ├── Free Tier Card
        └── Premium Tier Card
    ```

    **Free Tier Card:**
    - White/light gray card (`#f9fafb` background, border `#e5e7eb`, borderRadius 16, padding 20, marginBottom 16)
    - Header: "Free" title (bold, 20px) with a subtle badge or label
    - Feature rows (each row is a text line with a check or dash icon):
      - "Up to 20 guests"
      - "1 poll"
      - "3 potluck categories"
    - No CTA button — purely informational

    **Premium Tier Card:**
    - Amber/gold card (`#fffbeb` background, border `#f59e0b`, borderRadius 16, padding 20)
    - Header: "Premium" title (bold, 20px, color `#92400e`)
    - Feature rows:
      - "Unlimited guests"
      - "Unlimited polls"
      - "Unlimited potluck categories"
      - "White Elephant module"
      - "Gift Exchange module"
    - Each feature row should have a check icon (use lucide-react-native Check or CircleCheck, color `#d97706`)
    - "Request Access" CTA button at the bottom of the card:
      - Background: `#d97706` (amber-600), borderRadius 10, full width
      - Text: "Request Access", white, bold
      - Disabled state: `disabled={!eventId}` with reduced opacity

    **CTA behavior (same as PaywallBanner):**
    ```
    Alert.alert(
      "Request Premium Access",
      "You'll be taken to an external form to request Premium access.",
      [
        { text: "Cancel", style: "cancel" },
        { text: "Continue", onPress: () => WebBrowser.openBrowserAsync(UPGRADE_REQUEST_URL) }
      ]
    );
    ```

    **Do NOT:**
    - Show any price points ($X/month, etc.) — this is a stub CTA only
    - Call `plansApi.upgrade()` from this screen — pricing is demand-capture only (external URL)
    - Add this screen to tab navigation — it is only reachable via `router.push('/pricing?eventId=X')`
    - Use teal colors — amber/gold for premium, neutral gray for free

    **Imports:**
    - `useLocalSearchParams`, `useRouter` from expo-router
    - `Alert`, `ScrollView`, `View` from react-native
    - `SafeAreaView` from react-native-safe-area-context
    - `* as WebBrowser` from expo-web-browser
    - `Text` from @/components/ui/text
    - `Button`, `ButtonText` from @/components/ui/button
    - `AppHeader` from @/components/AppHeader
    - `UPGRADE_REQUEST_URL` from @/constants/upgrades
    - `Check` (or `CircleCheck`) from lucide-react-native for feature row checkmarks
