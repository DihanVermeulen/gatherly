<task type="auto">
  <name>Task 2: Add potluck signup CRUD with race guard</name>
  <files>apps/api/src/routes/modules.ts</files>
  <action>
Add signup routes in the POTLUCK MODULE section. **Wrap ALL handlers in `asyncHandler()`** following the existing pattern in this file.

**GET /:id/potluck/signups** (authenticateJWT — any event member)
- Wrap in `asyncHandler()`
- Query: `SELECT id, event_id, category_id, participant_name, note, created_at FROM module_potluck_signups WHERE event_id = $1 ORDER BY created_at ASC`
- Map to camelCase: `{ id, eventId, categoryId, participantName, note, createdAt }`

**POST /:id/potluck/signups** (authenticateJWT — both organizer and participant)
- Wrap in `asyncHandler()`
- Accept: `{ categoryId, participantName, note }` from req.body
- Validate: `categoryId` and `participantName` required
- Use a TRANSACTION with SELECT FOR UPDATE race guard:
  1. `BEGIN`
  2. `SELECT quantity FROM module_potluck_categories WHERE id = $1 AND event_id = $2 FOR UPDATE` — locks the row
  3. If category not found, ROLLBACK and return 404
  4. `SELECT COUNT(*)::int FROM module_potluck_signups WHERE category_id = $1` — count existing signups
  5. If count >= quantity, ROLLBACK and return `409 { error: 'slot_taken', message: 'Slot just taken' }`
  6. `INSERT INTO module_potluck_signups (event_id, category_id, participant_name, note) VALUES ($1, $2, $3, $4) RETURNING *`
  7. `COMMIT`
  8. Return 201 with created signup (camelCase mapped)
- CATCH: If error code is `23505` (unique constraint violation = same person signing up twice for same category), ROLLBACK and return `409 { error: 'slot_taken', message: 'Slot just taken' }`
- FINALLY: `client.release()`

**Identity handling:** The signup route must work for both token shapes:
- Organizer tokens have `userId` — resolve participant name from request body
- Participant tokens have `participantId` — still use `participantName` from request body (the mobile client sends it)
- Both are authenticated via `authenticateJWT` (no `requireOrganizer`)

**DELETE /:id/potluck/signups/:signupId** (authenticateJWT — both organizer and participant)
- Wrap in `asyncHandler()`
- `DELETE FROM module_potluck_signups WHERE id = $1 AND event_id = $2 RETURNING id`
- 404 if not found
- Note: Any authenticated event member can delete any signup for now (organizer management). The mobile client will only show the delete button for the current user's own signups.
