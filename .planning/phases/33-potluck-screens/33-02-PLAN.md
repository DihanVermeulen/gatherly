  <action>
Create potluck.tsx matching the Potluck-List.png template. This screen is accessible to ALL event members (organizers and participants).

**1. Header and Event Info**

- AppHeader with title "Potluck List", back button via `router.back()`.
- For organizers (`user?.participantId === undefined`), add right action: settings/gear icon that navigates to `/potluck-setup?id=${id}`.
- Below header: show event name (from EventsContext or fetched event).

**2. Event Readiness Progress Bar**

At the top, show a readiness summary card:
- "Event Readiness" label
- `{totalSignups}/{totalQuantity}` large text with "Items Claimed" subtitle
- `{percentage}% Complete` with a horizontal progress bar (teal fill)
- `{remaining} items still needed` subtitle below bar
- Calculate: `totalQuantity = sum of all active category quantities`, `totalSignups = signups.length`, `percentage = Math.round((totalSignups / totalQuantity) * 100)` (handle zero division)

**3. Categories Grouped List (ScrollView)**

For each category (filter out `status === 'draft'` categories — participants must NOT see draft ones):
- Category header: icon (Utensils from lucide-react-native), category name in caps, food image thumbnail if present
- For each slot in the category (iterate from 0 to `category.quantity - 1`):
  - Find matching signup from signups array where `signup.categoryId === category.id`
  - **Claimed slot**: Show participant name, suggestion chip text if available. If the current user's name matches the signup's participantName, show an "Un-signup" button (or swipe-to-delete, but button is simpler).
  - **Unclaimed slot**: Show suggestion chip text (from `category.suggestionChips[slotIndex]` if exists, otherwise generic item name from category name). Show teal "Signup" button.

**4. Signup Confirmation Sheet (Modal)**

When user taps "Signup" on an unclaimed slot, open a GlueStack Modal (size="lg"):
- Match Potluck-Signup.png template:
  - "Sign Up for Item" as header title with back/close button
  - Food image hero (from category's foodImageUrl, or a placeholder)
  - "SELECTED ITEM" label + item name (category name or suggestion chip text)
  - "Requested for {eventName}" subtitle
  - Description text: "Confirm you're bringing this item and let others know about any specific details like ingredients or if it's store-bought."
  - "Optional Note" label + multiline TextInput (placeholder "e.g., Homemade, contains dairy, gluten-free...")
  - Teal "Confirm" button (full width) — calls `modulesApi.createPotluckSignup(id, { categoryId, participantName, note })`
  - "Cancel" text link below
- **participantName resolution**: For organizers, use `user.name`. For magic-link participants, use `user.name` (both have name field on the user object from AuthContext).
- **409 handling**: If API returns 409 (slot_taken), close modal, show toast "This slot was just taken by someone else", and refresh the categories+signups data.
- **On success**: Close modal, refresh signups list, show success toast "You're signed up!"

**5. Un-signup Flow**

When user taps "Un-signup" on their own claimed slot:
- Show a confirmation Alert: "Remove your signup for {categoryName}?"
- On confirm: call `modulesApi.deletePotluckSignup(id, signupId)`
- Remove from local signups state
- Show toast "Signup removed"

**6. Data Loading**

On mount (useEffect with id dependency):
- Fetch categories: `modulesApi.getPotluckCategories(id)` — filter to only `status === 'active'` for display
- Fetch signups: `modulesApi.getPotluckSignups(id)`
- Set loading state during fetch

Use `useFocusEffect` (from @react-navigation/native) to refresh data when screen gains focus (same pattern as other screens in the app).

**7. Empty State**

If no active categories exist, show centered message: "No potluck items yet. The organizer hasn't set up the potluck." For organizers, add a "Set Up Potluck" button linking to potluck-setup.

**Styling**: Match Potluck-List.png closely. White card backgrounds, rounded-xl, shadow-sm. Teal (#0d9488) for Signup buttons and progress bar fill. Gray background (#f5f5f5 or similar). Category headers with subtle borders. Use GlueStack components throughout.
