  <action>
    **1. Create EventInvitesPage** at `apps/gatherly/src/pages/events/invites.tsx`:

    This is a protected page (already inside ProtectedRoute) for organizers to manage invites.

    **Page structure:**
    - Extract eventId from URL params: `useParams<{ id: string }>()`
    - Fetch event info from EventsContext (useEvents hook) to display event name in header
    - Fetch invites on mount: `invitesApi.getInvites(eventId)` -> store in local state
    - States: loading, error, invites list

    **Header section:**
    - Back button (link to /events/edit/:id)
    - Event name + "Invites" title
    - "Generate Invite" button (top right, emerald green, plus icon from Lucide)

    **Generate invite handler:**
    - Call `invitesApi.createInvite(eventId)` (no email, link-only)
    - On success: prepend new invite to list, optionally show the QR code modal for the new invite
    - On error: show error toast/message

    **Invite list:**
    - Each invite shows:
      - Status badge: "Pending" (yellow/amber), "Accepted" (green), "Declined" (red)
      - Participant name (if accepted, show name; if pending, show "Waiting...")
      - Email (if provided, show truncated email)
      - Created date (formatted relative: "2 hours ago" or "Jan 15")
      - Expires info (if expires_at, show "Expires: date"; if null, show nothing)
      - Action buttons row:
        - "QR" button - opens modal with InviteQRCode component for this invite's URL
        - "Copy" - inline InviteLink component (or just copy button)
        - "Revoke" button (only for pending invites) - red, trash icon
    - Empty state: "No invites yet. Generate one to share with participants." with a generate button

    **QR Code Modal:**
    - Simple overlay modal (dark backdrop, centered white card)
    - Shows InviteQRCode component with the invite URL
    - Close button (X in top right)
    - Below QR: InviteLink component with the full URL
    - Dismiss on backdrop click or Escape key

    **Revoke handler:**
    - Confirmation: "Are you sure you want to revoke this invite?" (window.confirm is fine)
    - Call `invitesApi.revokeInvite(eventId, inviteId)`
    - On success: remove invite from list
    - On error: show error message

    **Styling (consistent with existing pages):**
    - Container: `max-w-2xl mx-auto p-4`
    - Cards: `bg-zinc-800 rounded-xl p-4 mb-3`
    - Status badges: small rounded pills with appropriate colors
    - Buttons: Same emerald/red patterns used elsewhere
    - Use Lucide React icons: Plus, QrCode, Copy, Trash2, ArrowLeft, Check, Clock, UserCheck

    - Add inside the ProtectedRoute children, after the wishlist route:
      ```tsx

      },
      ```

    **3. Add navigation link** in `apps/gatherly/src/pages/events/edit.tsx`:

      - Text: "Manage Invites" or "Share Invites"
      - Icon: Lucide UserPlus or Share2
      - Style: consistent with existing action buttons on the edit page
    - This should be prominent since invite sharing is a key organizer action
    - Use React Router's `Link` or `useNavigate` (follow existing patterns in edit.tsx)
