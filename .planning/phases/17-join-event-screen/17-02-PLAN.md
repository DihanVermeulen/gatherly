  <action>
    Replace the entire join.tsx placeholder with a full implementation. This is a complete rewrite — do NOT patch the existing 19-line stub.

    **State machine:**
    ```typescript
    type JoinState = 'loading' | 'preview' | 'joining' | 'success' | 'already-joined' | 'invalid' | 'error';
    ```

    **Imports needed:**
    - `useState`, `useEffect` from react
    - `View`, `StyleSheet`, `Image` from react-native (Image for the "come back later" graphic — use a lucide icon instead if no asset)
    - `useLocalSearchParams`, `useRouter`, `Stack` from expo-router
    - `useSession` from `./contexts/AuthContext`
    - `useEvents` from `./contexts/EventsContext`
    - `invitesApi`, `InvitePreview` from `./api/invites`
    - `eventsApi` from `./api/events`
    - `setPendingInviteCode` from `./utils/pendingInvite`
    - GlueStack: `Text`, `Button`, `ButtonText`, `Heading`, `VStack`, `Spinner`
    - GlueStack: `Skeleton`, `SkeletonText` from `@/components/ui/skeleton`
    - Lucide icons: `CheckCircle`, `AlertTriangle`, `WifiOff`, `PartyPopper` (or similar — Claude's discretion for success/error icons)

    **Component structure:**

    At the top of the component, render `<Stack.Screen options={{ headerShown: false, gestureEnabled: false }} />` to enforce no-header no-gesture (belt-and-suspenders with _layout.tsx).

    **State variables:**
    - `joinState: JoinState` — starts at 'loading'
    - `previewData: InvitePreview | null` — from validate response
    - `eventDetails: { date?: string; organizerName?: string; participantCount?: number } | null` — from getById (auth only)
    - `joinedEventId: number | null` — set after successful accept
    - `networkAttempts: number` — tracks failed join attempts (max 3)
    - `inlineError: string | null` — error text shown below Join button

    **Hero color:**
    Use the same HERO_COLORS array from event-details.tsx (copy it — it's 6 hex values). Derive color: `HERO_COLORS[previewData.eventId % HERO_COLORS.length]`. Use with inline `style={{ backgroundColor: heroColor }}` — NOT className (locked decision: NativeWind cannot resolve dynamic hex at runtime).

    **On mount effect (validate):**
    1. If `!token`, set state to 'invalid' immediately
    2. Call `invitesApi.validate(token)`
    3. On success: store previewData, set state to 'preview'
    4. On 404 error: set state to 'invalid'
    5. On network error: set state to 'error'
    6. If user is authenticated (`session` exists), also call `eventsApi.getById(String(previewData.eventId))` to get organizer name, participant count, and date. Store in eventDetails. This call may fail (user might not be a member yet) — that's fine, just leave eventDetails null.
    7. CRITICAL: For unauthenticated users, `eventsApi.getById` requires auth and will fail. Only call it when `session` exists. Unauthenticated preview shows event name only — organizer/count/date shown as unavailable.

    **Already-joined check (effect):**
    After validate succeeds AND user is authenticated, check EventsContext:
    ```typescript
    const existingEvent = events.find(e => e.id === String(previewData.eventId));
    if (existingEvent && existingEvent.people?.includes(user.name)) {
      setJoinState('already-joined');
    }
    ```
    This is best-effort — if the event isn't in context yet, proceed to preview (accept is idempotent).

    **Auto-join on auth state change:**
    If the user arrives at the join screen already authenticated (e.g., redirected back from sign-in with pending invite code), AND previewData is loaded, AND the user is NOT already joined, automatically trigger handleJoin(). Detect this with a `useEffect` watching `session` — if session transitions from null to truthy while in 'preview' state, call handleJoin().

    **handleJoin function:**
    1. Require auth: if `!session || !user`, call `setPendingInviteCode(token)` and `router.push('/sign-in')`, return
    2. Set state to 'joining' (full-screen overlay)
    3. Call `invitesApi.accept(token, user.name, user.email)`
    4. On success: set joinedEventId, call `refreshEvents()`, set state to 'success'
    5. On network error: increment networkAttempts, set inlineError, set state back to 'preview'
    6. On 404 error: set state to 'invalid'

    **Success auto-navigate (effect):**
    When state is 'success' and joinedEventId is set, start a 2-second timer then `router.replace(\`/event-details?id=${joinedEventId}\`)`.

    **Rendering per state:**

    **'loading' state:**
    Full-screen skeleton mimicking the hero + card layout:
    - Skeleton rounded box (h-48, mx-4, mt-4, rounded-2xl) for hero area
    - SkeletonText 1 line (h-8, w-3/4) for event name
    - SkeletonText 2 lines (h-4) for details
    - Skeleton rounded box (h-12) for button

    **'preview' state:**
    Full-screen layout with:
    - Hero area: colored rectangle (h-48, mx-4, mt-16, rounded-2xl) with `style={{ backgroundColor: heroColor }}`, centered large event name text (white, bold, text-3xl)
    - Below hero (px-4, mt-6):
      - Event name heading (text-2xl, bold)
      - If eventDetails available: organizer name, participant count ("N participants"), event date — each as Text with typography-500
      - If eventDetails not available (unauthenticated): just event name from previewData
    - If authenticated: large "Join Event" Button (size xl, primary, rounded-2xl, w-full, mt-6)
    - If NOT authenticated: large "Log in to Join" Button (size xl, primary, rounded-2xl, w-full, mt-6). onPress: `setPendingInviteCode(token); router.push('/sign-in')`
    - If inlineError: show error Text below button (text-error-500, text-sm, mt-2)
    - If networkAttempts >= 3: replace the entire button area with a "Come back later" state: centered VStack with WifiOff icon (size 64, color typography-300), "Something went wrong" heading, "Please try again later" text, no retry button

    **'joining' state:**
    Show the preview layout underneath, with a full-screen semi-transparent overlay on top:
    ```tsx
    <View style={StyleSheet.absoluteFillObject} className="bg-black/50 items-center justify-center z-50">
      <Spinner size="large" className="text-white" />
      <Text className="text-white mt-4 text-lg">Joining event...</Text>
    </View>
    ```
    Use `Spinner` from `@/components/ui/spinner` (NOT ButtonSpinner — locked decision).

    **'success' state:**
    Centered full-screen with:
    - CheckCircle icon (size 64, color emerald-500)
    - "You're in!" heading (text-2xl, bold)
    - "Taking you to {eventName}..." text (typography-500)
    - The auto-navigate timer handles transition

    **'already-joined' state:**
    Centered full-screen with:
    - Hero area with event color (same as preview)
    - "You're already a member" heading
    - "You've already joined {eventName}" text
    - "View Event" Button that calls `router.replace(\`/event-details?id=${previewData.eventId}\`)`

    **'invalid' state:**
    Centered full-screen with:
    - AlertTriangle icon (size 64, color amber-500)
    - "This invite is no longer valid" text (per CONTEXT — no distinction between invalid vs expired)
    - A "Go Home" Button that navigates to the events tab: `router.replace('/(tabs)')`

    **'error' state:**
    Centered full-screen with:
    - AlertTriangle icon (size 64, color error-500)
    - "Something went wrong" heading
    - "We couldn't load this invite. Please check your connection and try again." text
    - "Try Again" Button that re-runs the validate flow (reset state to 'loading' and re-trigger validate effect)
    - "Go Home" Button (outline variant) as secondary action

    **CRITICAL PITFALLS TO AVOID:**
    - Use `token` as the query param name (not `code`) — matches existing deep link URL format
    - Pass token as `code` to invitesApi.validate: `invitesApi.validate(token)`
    - Use `user.name` from useSession as participantName for accept — NO name input form
    - Use `Spinner` not `ButtonSpinner` for the overlay
    - Use inline `style={{ backgroundColor: heroColor }}` for dynamic hex colors
    - Use `router.replace` (not push) for post-join navigation — prevents back-to-join
    - Handle 429 rate limit responses the same as invalid: show generic error
