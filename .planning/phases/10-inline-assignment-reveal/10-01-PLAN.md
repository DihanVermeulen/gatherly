    **Backend (apps/api/src/routes/events.ts):**

    Add a new route `GET /:id/my-assignments` protected by `authenticateJWT` only (NOT requireOrganizer — that blocks participants). Place it after the existing single-event GET route.

    Implementation:
    1. Parse `eventId` from `req.params.id` (parseInt, base 10)
    2. Extract `participantId` from `req.user!` — if falsy, return 403 `{ error: "Participant access required" }`
    3. Verify the participant belongs to this event: `SELECT id FROM participants WHERE id = $1 AND event_id = $2` with `[participantId, eventId]`. If no rows, return 403 `{ error: "You are not a participant in this event" }`
    4. Query assignments: `SELECT receiver.name as receiver_name FROM assignments a JOIN participants receiver ON a.receiver_id = receiver.id WHERE a.event_id = $1 AND a.giver_id = $2` with `[eventId, participantId]`
    5. Map rows to `receivers: string[]`. If empty, return 404 `{ error: "No assignments found yet" }`
    6. Return `res.json({ receivers })`

    **Frontend (apps/gatherly/src/api/events.ts):**

    Add a new function to the `eventsApi` object:
    ```typescript
    getMyAssignments: async (eventId: string): Promise<{ receivers: string[] }> => {
      const response = await apiClient.get(`/api/events/${eventId}/my-assignments`);
      return response.data;
    },
    ```

    Place it after the existing `getCodes` function, before the closing brace of eventsApi.

    **2. Add reveal state inside the component (before the return):**
    ```typescript
    type RevealState = "idle" | "loading" | "revealed" | "error" | "no-assignments";
    ```
    Note: Define the type outside the component. Inside the component add:
    ```typescript
    const [revealState, setRevealState] = useState<RevealState>("idle");
    const [myReceivers, setMyReceivers] = useState<string[]>([]);

    const isParticipant = user?.role === "participant" && !!user?.participantId;

    const handleReveal = async () => {
      if (!id) return;
      setRevealState("loading");
      try {
        const data = await eventsApi.getMyAssignments(id);
        setMyReceivers(data.receivers);
        setRevealState("revealed");
      } catch (err: any) {
        if (err.response?.status === 404) {
          setRevealState("no-assignments");
        } else {
          setRevealState("error");
        }
      }
    };
    ```

    **3. Replace the "Secret Assignment Section" (the div with comment `{/* Secret Assignment Section */}`):**

    Keep the outer card container (`div.mt-4.bg-white...rounded-2xl`). Replace the inner content with role-conditional rendering:

      - **idle state:** Show heading "Your Secret Assignment", description "Tap below to reveal who you're buying for!", and a green "Reveal My Assignment" button with Eye icon that calls `handleReveal`

      - **revealed state:** Show heading "You're Buying For:", then map `myReceivers` to styled name badges (each in a `div` with green background accent, bold text, good spacing). Below, a subtle "Keep it secret!" reminder text.
      - **no-assignments state:** Show heading and text "Assignments haven't been generated yet. Check back later!" with a muted style.
      - **error state:** Show heading and text "Something went wrong. Please try again." with a "Try Again" button that resets to idle.
