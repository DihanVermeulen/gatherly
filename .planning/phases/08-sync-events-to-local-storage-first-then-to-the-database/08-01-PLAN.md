3. Create `apps/gatherly/src/lib/queryClient.ts`:
   - Import `QueryClient` and `MutationCache` from `@tanstack/react-query`
   - Import `eventsApi` from `../api/events` (for mutation defaults)
   - Create and export a `queryClient` with these defaults:
     - `queries.gcTime`: 24 hours (1000 * 60 * 60 * 24)
     - `queries.staleTime`: 5 minutes (1000 * 60 * 5)
     - `queries.networkMode`: `'offlineFirst'`
     - `mutations.networkMode`: `'offlineFirst'`
     - `mutations.retry`: 3
     - `mutations.retryDelay`: exponential backoff `(attempt) => Math.min(1000 * 2 ** attempt, 30000)`
   - Add a `MutationCache` with an `onSuccess` logger: `console.log('Mutation synced:', mutation.options.mutationKey)`
   - Set mutation defaults for event operations using `queryClient.setMutationDefaults`:
     - `['event', 'create']`: calls `eventsApi.create(vars.name, vars.coupleCrossing)`
     - `['event', 'update']`: calls `eventsApi.update(vars.id, vars)` (destructure id from rest)
     - `['event', 'delete']`: calls `eventsApi.delete(vars)` (vars is the id string)
   - NOTE: Do NOT instantiate QueryClient inside a component. Create it at module scope.

4. Create `apps/gatherly/src/lib/queryPersister.ts`:
   - Import `createSyncStoragePersister` from `@tanstack/query-sync-storage-persister`
   - Create and export a `persister` using `window.localStorage` with key `'gatherly-query-cache'`

5. Create `apps/gatherly/src/lib/migrateStorage.ts`:
   - Constants: `OLD_STORAGE_KEY = 'secret_santa_events'`, `MIGRATION_VERSION_KEY = 'gatherly-migration-version'`
   - Export function `migrateFromV1()`:
     - Check `localStorage.getItem(MIGRATION_VERSION_KEY)` - if equals `'2'`, return early (already migrated)
     - Read old data from `localStorage.getItem(OLD_STORAGE_KEY)`
     - If old data exists, parse it, normalize events (add `wishlists: []` and `gifts: {}` defaults)
     - Write the migrated events array to `localStorage.getItem('gatherly-events-v1-backup')` as a backup
     - Set `localStorage.setItem(MIGRATION_VERSION_KEY, '2')`
     - Log migration count to console
     - Do NOT delete the old key yet (safety during transition)
     - Wrap everything in try/catch - never throw, just log errors
   - This function will be called in `index.tsx` BEFORE React renders, so the data is available when TanStack Query hydrates
