<task type="auto">
  <name>Task 2: Integrate Konsta UI v5 with iOS theme</name>
  <files>
    apps/gatherly/package.json
    apps/gatherly/tailwind.config.js
    apps/gatherly/src/styles/global.css
    apps/gatherly/public/index.html
  </files>
  <action>
    1. Install Konsta UI:
       ```bash
       cd apps/gatherly
       pnpm add konsta
       ```

    2. Update `tailwind.config.js` to include Konsta UI plugin:
       ```js
       const konstaConfig = require('konsta/config');

       module.exports = konstaConfig({
         content: ["./src/**/*.{js,jsx,ts,tsx}", "./public/index.html"],
         darkMode: 'class',
         theme: {
           extend: {
             colors: { primary: '#13ec5b' },
             fontFamily: { sans: ['Plus Jakarta Sans', 'sans-serif'] },
           },
         },
         plugins: [],
       });
       ```
       Note: `konstaConfig()` wraps the standard Tailwind config and adds Konsta UI's required theme extensions. This is the official integration pattern from Konsta UI docs.

    3. Add Konsta UI CSS import to `global.css` AFTER the Tailwind directives:
       ```css
       @tailwind base;
       @tailwind components;
       @tailwind utilities;

       /* Konsta UI theme - must come after Tailwind directives */
       @import 'konsta/konsta.css';

       @layer utilities {
         .line-clamp-2 {
           overflow: hidden;
           display: -webkit-box;
           -webkit-box-orient: vertical;
           -webkit-line-clamp: 2;
         }
       }
       ```

    4. Add Plus Jakarta Sans and Material Symbols fonts to `public/index.html` in the `<head>`:
       ```html
       <link rel="preconnect" href="https://fonts.googleapis.com" />
       <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
       <link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap" rel="stylesheet" />
       <link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined" rel="stylesheet" />
       ```

    5. Do NOT wrap the entire app in `<App theme="ios">` yet - that will be done in Phase 5 (Mobile UI Redesign) when pages are rebuilt. Konsta UI components can be used individually before the full app wrapper is added.

    6. Verify the integration:
       ```bash
       cd apps/gatherly && pnpm build
       ```
  </action>
  <verify>
    Run `cd apps/gatherly && pnpm build` - must complete without errors.
    Run `pnpm list konsta` in apps/gatherly - must show version 5.x or higher.
    Confirm `konsta/konsta.css` is importable (build would fail if not).
  </verify>
  <done>
    Konsta UI v5 installed, Tailwind config wrapped with konstaConfig, Konsta CSS imported in global styles, Plus Jakarta Sans and Material Symbols fonts added to index.html. Build succeeds.
  </done>
</task>
