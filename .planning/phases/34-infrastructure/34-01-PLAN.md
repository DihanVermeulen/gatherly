    ```typescript
    // PATCH /api/events/:id/upgrade — promote event to premium tier (idempotent)
    router.patch(
      "/:id/upgrade",
      authenticateJWT,
      requireOrganizer,
      asyncHandler(async (req: Request, res: Response) => {
        const { id } = req.params;
        const result = await query(
          "UPDATE events SET plan_tier = 'premium' WHERE id = $1 AND organizer_id = $2 RETURNING id",
          [id, (req as any).user.userId],
        );
        if (result.rowCount === 0) {
          return res.status(403).json({ error: "Forbidden" });
        }
        const updatedEvent = await fetchEventById(id);
        res.json(updatedEvent);
      }),
    );
    ```

    fetchEventById is already defined as a file-scoped function in events.ts — no import is needed.
    asyncHandler, authenticateJWT, requireOrganizer are already imported at the top of events.ts.
    The route is idempotent: calling it when plan_tier is already 'premium' still matches the WHERE clause and returns the event.
