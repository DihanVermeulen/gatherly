## Milestone Summary

**Key Decisions:**

- GlueStack UI over Konsta UI — already installed and scaffolded; Konsta was v2.0 plan
- Expo Router for navigation — file-based routing, matches React Router mental model
- SecureStore for token persistence — accessToken + user JSON; refreshToken lives in HttpOnly cookie only
- signOutCallback pattern — client.ts interceptor calls AuthContext's signOut then router.replace on 401
- EventsProvider key={session} OUTSIDE Stack.Protected — React destroys/remounts on session change; prevents impossible UI combinations
- expo-sqlite via npm --ignore-scripts — pnpm fails due to monorepo virtual store path length
- async-storage pinned to 1.24.0 — version 1.24.1 was unpublished from npm registry
- SQLite singleton pattern: module-level let db = null in database.ts
- Smart magic-link redemption: /redeem email-matches users table; if match found, issues user-scoped JWT
- participantId-as-session-discriminant: user.participantId !== undefined = magic-link participant; absence = full account user — role field dropped
- JoinState machine pattern: 7-state union type + switch in renderContent()
- /lookup endpoint read-only pattern: POST /api/auth/magic-link/lookup — no participant creation, no token consumption

**Issues Resolved:**

- EventsProvider remount pattern: 19-04 approach broke Expo Router; 19-05 reverted to key={session} outside Stack.Protected
- Phase 27 smart join flow: multiple gap closures (27-03, 27-04, 29-01 through 29-03) needed to fully wire account linking and magic-link join UX
- Phase 28 role removal: requireOrganizer middleware updated to use participantId discriminant

**Issues Deferred:**

- GAP-01: join.tsx missing refreshEvents() after invitesApi.accept() — QR code join flow may land on empty event-details (accepted as tech debt)
- assetlinks.json SHA-256 fingerprint + associatedDomains YOUR_DOMAIN are placeholders — must be replaced before production Universal/App Links work
- modules-config, polls, rsvp routes not registered in _layout.tsx — cosmetic (file-based routing resolves them but no headerShown config)

**Technical Debt Incurred:**

- Phase 18 + 22-24 have no VERIFICATION.md — functionality confirmed by integration check and UAT
- Phase 19-05 left EventsProvider without key={session} in current codebase per integration check (mitigated by session-null dispatch)
