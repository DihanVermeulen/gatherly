# Requirements: Gatherly v2.0

**Defined:** 2026-02-06
**Core Value:** Participants can easily discover what gifts people actually want and claim them anonymously, eliminating gift-giving guesswork while keeping the surprise element intact.

## v2.0 Requirements

### Wishlist Management

- [x] **WISH-01**: User can create wishlist items with name, description, and image — *delivered Phase 2*
- [x] **WISH-02**: User can set priority level on wishlist items (high/medium/low) — *delivered Phase 2*
- [x] **WISH-03**: User can edit their own wishlist items — *delivered Phase 2*
- [x] **WISH-04**: User can delete their own wishlist items — *delivered Phase 2*
- [x] **WISH-05**: User can add product URL links to wishlist items — *delivered Phase 2*
- [x] **WISH-06**: User can reorder wishlist items via drag-and-drop — *delivered Phase 6 (UAT 8/8 passed)*
- [x] **WISH-07**: Participants can view other participants' wishlists — *delivered Phase 2*

### Gift Claiming

- [x] **CLAIM-01**: Participant can anonymously claim a gift from another participant's wishlist — *delivered Phase 3*
- [x] **CLAIM-02**: Participant can unclaim a gift if plans change — *delivered Phase 3*
- [x] **CLAIM-03**: System prevents duplicate claims with race condition protection — *delivered Phase 3 (UNIQUE constraint + INSERT ON CONFLICT)*
- [x] **CLAIM-04**: Claimed status is visible only to the claimer, not the wishlist owner — *delivered Phase 3*

### Invite System

- [x] **INV-01**: Organizer can generate shareable invite links for events — *delivered Phase 4-01 + Phase 9*
- [x] **INV-02**: Organizer can generate QR codes for event invites — *delivered Phase 4-02*
- [x] **INV-03**: Participants can join events via invite link or QR code — *delivered Phase 4-02 (public /join/:code page)*

## Out of Scope

| Feature | Reason |
|---------|--------|
| Mandatory user accounts | Reduces friction for participants, localStorage fallback allows offline use |
| Email notification spam | 2026 Gmail crisis shows users hate email overload, keep minimal |
| Price tracking / deal alerts | Scope creep into price comparison, out of core value |
| AI gift suggestions | Users distrust AI in intimate gift contexts per research |
| In-app purchasing | Payment compliance nightmare, gifts purchased externally |
| Real-time updates (WebSocket) | Polling/refresh sufficient for v2.0, adds complexity |
| Multiple events per participant | Single event focus simplifies UX for v2.0 |
| Gift reveal animations | Polish feature, defer until core features validated |
